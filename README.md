# 🛒 TechShop - Vitrine de E-commerce Responsivo

Uma interface moderna e dinâmica de e-commerce desenvolvida com **HTML5**, **CSS3** e **JavaScript Puro (Vanilla JS)**. O projeto foi construído utilizando a metodologia **Mobile-First**, garantindo excelente usabilidade em dispositivos móveis e desktops, e serve como componente de portfólio para desenvolvimento Front-end.

---

## 🚀 Funcionalidades e Recursos

*   **Design Responsivo (Mobile-First):** Layout estruturado com **Flexbox** e otimizado nativamente para smartphones, adaptando-se de forma fluida para telas maiores (tablets e computadores) através de **Media Queries**.
*   **Interatividade com o Carrinho:** Lógica em JavaScript para escuta de eventos e manipulação dinâmica do **DOM** (Document Object Model), incrementando o contador de itens no cabeçalho em tempo real.
*   **Acessibilidade Visual:** Uso de paleta de cores corporativa com alto contraste e feedbacks visuais amigáveis ao usuário (efeito *hover* nos cards de produtos).

---

## 🛠️ Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica da página.
*   **CSS3:** Estilização moderna, Flexbox, Media Queries e efeitos de transição.
*   **JavaScript (ES6+):** Manipulação de dados em memória e controle dinâmico da interface.
*   **Versionamento:** Git & GitHub.
*   **Hospedagem:** GitHub Pages.

## 📦 Como Visualizar o Projeto Localmente

### 1. Clonar o repositório
```bash
git clone https://github.com
cd techshop-responsivo
```

### 2. Abrir o projeto
Como o projeto utiliza tecnologias nativas da web, basta abrir o diretório e dar **dois cliques no arquivo `index.html`** para executá-lo diretamente em qualquer navegador de internet (Chrome, Edge, Firefox).
